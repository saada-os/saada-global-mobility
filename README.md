# Saada Global Mobility

Portable Bolt-compatible source for the Saada Global Mobility website.

## Editing in Bolt

1. Open the project in Bolt.
2. Describe the desired change in normal language.
3. Review the preview in German, English and Arabic.
4. Ask Bolt to fix anything that is incorrect.
5. Press **Publish** only after the preview is approved.

Bolt reads `claude.md` as permanent project guidance. It protects the three-language structure, Arabic layout, brand, pricing distinction and legal boundaries.

## Local development

```bash
npm install
npm run dev
```

Production check:

```bash
npm run build
```
